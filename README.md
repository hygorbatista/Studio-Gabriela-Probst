# Studio Gabriela Probst

Sistema de gestão para studio de unhas (fibra de vidro, gel) — agendamento,
clientes, financeiro e analytics.

## Stack
- Next.js 16 (React 19 + TypeScript)
- Tailwind CSS
- Supabase (PostgreSQL)
- Deploy: Vercel

## Como rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000
